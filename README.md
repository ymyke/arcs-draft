# Arcs draft

A small web page for drafting leader and lore cards in [Arcs](https://boardgamegeek.com/boardgame/359871/arcs) before game night. Everyone picks in their own time, with room to think about combos, and setup at the table goes quickly. One person enters the names and deals. Every pick produces a new link, which goes to the next player. The whole draft lives in that link, so there is no server, no account and nothing to install.

Unofficial fan tool, not affiliated with Leder Games or Buried Giant Studios. Card text comes from the [official card library](https://cards.buriedgiant.com).

## How a draft works

The page follows the Leaders & Lore setup from the rulebook. Turn order is shuffled, and the first name holds initiative. Picks start with the player to the right of initiative and go counterclockwise. Each turn a player takes one card, until everyone holds one leader and their lore cards.

Variants, all chosen at setup and carried in the link:

| Setting | Choices |
|---|---|
| Cards | Base game only (8 leaders, 14 lore), or base game plus the Leaders & Lore pack (16 leaders, 28 lore) |
| Lore cards each | 1 (rulebook), 2 (the rulebook's variant) or 3 |
| Cards on offer | **Rulebook rows**: one more leader than players, and one more lore card than the players take in total. **Wider rows**: twice as many leaders as players, and lore + 2 lore cards per player. **Deal and pick**: each player gets a hand of 2 leaders and lore + 1 lore cards to choose from. |
| Pick order | **Rulebook**: the same order every round. **Snake**: the order reverses each round. |

In deal and pick, every hand is visible to anyone who opens the link.

## Development

Plain ES modules with no build step. The repo root is the site, so GitHub Pages can serve it as is.

```sh
npm install        # jsdom, for the UI tests
npm start          # http://localhost:8000 — modules don't load from file://
npm test           # node:test, unit and UI tests
npm run sync-cards # regenerate src/cards.js from the official card library
```

Requires Node 22 or later.

| Path | Contents |
|---|---|
| `src/cards.js` | Leader and lore card data, generated by `scripts/sync-cards.mjs` |
| `src/draft.js` | Draft rules as pure functions: row sizes, dealing, pick order, pick legality |
| `src/codec.js` | Encoding a draft into the link and decoding it back, with full validation |
| `src/text.js` | Rendering card text markup to HTML |
| `src/app.js` | Views and event handling; `mount(root, window)` starts the page |
| `test/` | Unit tests for each module, plus UI tests that mount the page in jsdom |

### The link format

The hash holds base64url text with five fields separated by `|`: player names joined with `~`, the leader row, the lore row, the picks, and the options. Rows list card indices in base 36, one character each. Each pick is one letter, `A`–`Z` for a leader slot and `a`–`z` for a lore slot. Links made before variants existed have only the first four fields, and they still open with the rulebook settings.

Because links store cards by their position in `src/cards.js`, cards may only ever be appended. The sync script refuses to write a file that would reorder or remove a card.

### Card text and errata

`npm run sync-cards` downloads the card library and applies published errata that change card text. It warns about any new erratum for these cards that hasn't been reviewed yet. The errata currently applied are Upstart's *Callow*, Agitator's *Irregular* and Living Structures' *Prune*.
